# Example: a development workstream (fictional)

A made-up to-do app called "Lumen Todo" is adding reminders. This example shows a snapshot partway through:

- W-01 "Reminders" grew big enough that its lead session was promoted to a manager with four task sessions.
- W-02 "Login bug" stayed small: one lead session, no split.

Open the files under `en/memory-bank/` (Korean: `ko/memory-bank/`) in this order: `sessions.md`, `progress.md`, `workstreams/W-01_reminders.md`, `activeContext.md`, `worklog/`.
Everything here is invented for illustration.
