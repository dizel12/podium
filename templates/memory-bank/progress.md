# Progress

Workstream list. Only the main session adds new entries and assigns new IDs, so IDs never collide.
The workstream's own session updates its own entry.

### W-01. <workstream title>
- Status: in progress | waiting | on hold | backlog | done
- Priority: top | high | normal | low
- Started: YYYY-MM-DD / Finished: YYYY-MM-DD
- Goal:
- Related files:
- Notes:

When a workstream is done, set Status to done and leave a note in `worklog/`.
