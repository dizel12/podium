# Security

If you find a problem that could harm someone who installs podium (for example a procedure that makes Claude write secrets to a file, or run something the user did not approve), please report it privately through GitHub: **Security** tab, **Report a vulnerability**. Please do not open a public issue for it.

podium is Markdown and JSON with no code that runs by itself, so reports are mostly about instructions that could lead Claude to do something unsafe.
